# LIVE ROUND

https://rak-kr.github.io/live-round/

지하실 테이블, 산탄총 한 자루, 가면을 쓴 상대. 실탄과 공포탄이 섞인 총으로 번갈아 쏘는 테이블 호러 게임입니다.

## 모드
- **캠페인** — 가면을 쓴 상대 5명(문지기 → 재봉사 → 웃는 자 → 외눈 → 주인). 각 상대와 3라운드를 치르며, 이기면 다음 상대가 열립니다.
- **더블 오어 낫싱** — 라운드를 이길 때마다 상금이 두 배가 됩니다. 현금화하거나 전부를 걸고 계속합니다. 죽으면 모두 잃습니다.
- **빠른 대결** — 난이도(쉬움/보통/어려움/악몽)를 골라 봇과 3라운드.
- **친구와 하기** — 2~4명. 방을 만들면 5자리 코드와 초대 링크가 나옵니다. 빈자리는 봇으로 채울 수 있고, 3라운드 동안 가장 많이 살아남은 사람이 이깁니다. 서버 없이 P2P(PeerJS)로 연결됩니다.

## 아이템 (9종)
돋보기, 수갑, 톱, 맥주, 담배, 아드레날린, 대포폰, 인버터, 상한 약

## 조작
- 하단 버튼: 상대를 쏜다 / 나를 쏜다 (키보드 1 / 2)
- 테이블 위 내 아이템을 누르면 설명과 사용 버튼이 나옵니다.
- 아드레날린 사용 후 상대 아이템을 눌러 빼앗습니다.
- ESC 또는 우측 상단 II: 일시 정지

## 구조
```
index.html
css/style.css
js/main.js      화면 흐름, 연출, 입력
js/game.js      규칙 (DOM 없음)
js/ai.js        봇 판단
js/render.js    Three.js 3D 장면 (저해상도 렌더 + 디더링/그레인 후처리)
js/lib/         three.module.min.js (r160, MIT), peerjs.min.js (1.5.4, MIT)
js/audio.js     Web Audio 합성 사운드
js/campaign.js  캠페인 상대와 대사
js/net.js       친구 대전 P2P 연결 (방장이 판정, 참가자는 행동만 전송)
tests/sim.js    봇 대 봇 4000판 시뮬레이션 (node tests/sim.js)
```

## 배포 (GitHub Pages)
저장소에 파일을 폴더 구조 그대로 올린 뒤 Settings → Pages → Branch: main / root 로 설정합니다.

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭해서 열면 동작하지 않습니다. 로컬에서는 `npx serve` 또는 `python -m http.server`처럼 간단한 서버로 여세요.
